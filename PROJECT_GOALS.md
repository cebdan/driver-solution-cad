# Цели и хотелки проекта

## Основная цель проекта
Создание CAD системы с микроядром на основе абстрактного класса `Solution`.

## Архитектура

### Микроядро Solution
- [x] Абстрактный класс `Solution` с методами:
  - [x] `new_solution()` - создание нового решения
  - [x] `delete_solution()` - удаление решения
  - [x] `copy()` - копирование
  - [x] `duplication()` - дублирование
  - [x] `propagation()` - распространение
  - [x] `similar_make()` - создание похожего

### История построения
- [x] Класс `ConstructionHistory` для отслеживания операций
- [ ] Реализация undo/redo функциональности

### Система нодов
- [x] Базовый класс `Node` для скриптов
- [ ] Реализация вычислительных графов
- [ ] Визуальный редактор нодов

### GUI (XTD)
- [x] Интеграция xtd framework
- [x] Главное окно приложения
- [x] Меню приложения
- [ ] Окно терминала (GUI версия)
- [ ] Редактор документов
- [ ] 3D вид (OpenGL)

### OpenGL 2.1
- [x] Интерфейс `OpenGLRenderer`
- [ ] Реализация 3D рендеринга
- [ ] Интеграция с документами

### Обмен данными
- [x] Интерфейс `DataExchangeInterface`
- [ ] Реализация обмена между Solution объектами

## Классы данных

### Value
- [x] Класс `Value` от `Solution`
- [x] Поддержка типов: int, double, string, bool, pointer
- [x] Конвертация между типами
- [x] Арифметические операции

### CS (Coordinate System)
- [x] Класс `CS` от `Solution`
- [x] Позиция: x, y, z
- [x] Поворот: a, b, c
- [x] Глобальный CS: (0,0,0,0,0,0)
- [x] Трансформации

### Точки
- [x] `Point2D` - 2D точки (CS, x, y)
- [x] `Point3D` - 3D точки (CS, x, y, z)
- [x] Геометрические операции
- [x] Трансформации
