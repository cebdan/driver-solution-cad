# Текущая стадия разработки

## Общее состояние проекта

Проект находится на стадии **перехода с xtd на ImGui + SDL2**. Создана новая версия GUI приложения на ImGui, которая обеспечивает полный контроль над окнами и лучшую интеграцию с OpenGL для будущего 3D рендеринга.

## ⚠️ ВАЖНО: Переход на ImGui + SDL2

**xtd framework показал себя плохо** - проблемы с управлением окнами (кнопки не скрывались), сложная интеграция с OpenGL, тяжелые зависимости.

**Новое решение**: ImGui + SDL2
- ✅ Полный контроль над окнами (легко скрыть кнопки на macOS)
- ✅ Идеальная интеграция с OpenGL
- ✅ Легковесность и производительность
- ✅ Гибкость для кастомных виджетов

## Что реализовано и работает

### ✅ GUI Приложение (simple_gui)
- **Главное окно "Solution manager"** - полностью функциональное окно с заголовком
- **Меню приложения**:
  - **File**: New 2D Document, Open, Save, Quit (с горячими клавишами Cmd+N, Cmd+O, Cmd+S, Cmd+Q)
  - **Manager**: Open Manager, 2D Solutions, 3D Solutions, Draft Solutions, BOM Solution
  - **Help**: Implementation Notes, Project Goals, About
- **Кнопки в окне**: 2d solutions, 3d solutions, Draft solutions, Bom solution, Load Image
- **Отображение изображений**: Автоматическая загрузка изображения из проекта или ручной выбор через диалог
- **Статусная строка**: Отображение текущего статуса операций

### ✅ Поведение окна
- Окно скрывается при закрытии (красная кнопка), но приложение продолжает работать
- Меню остается доступным даже когда окно скрыто (благодаря статическим объектам меню)
- Закрытие приложения через File → Quit или Cmd+Q работает корректно
- При нажатии "2D Solutions" окно минимизируется в Dock (нативный macOS вызов)

### ✅ Нативная macOS интеграция
- Реализован модуль `macos_window_utils.mm` с Objective-C++ кодом для управления окнами
- Функции для скрытия кнопок окна через NSWindow API
- Функция минимизации окна через нативный `[window miniaturize:nil]`
- Делегат окна для отслеживания событий окна

### ✅ Документация
- `IMPLEMENTATION_NOTES.md` - технические заметки, проблемы и решения
- `PROJECT_GOALS.md` - цели проекта и чеклист задач
- Ссылки на документацию доступны через меню Help

## Текущие проблемы и ограничения

### ⚠️ Проблема: Кнопки окна (красная и зеленая) все еще видны
**Статус**: Частично решено, но не полностью

**Что сделано**:
- Реализован нативный macOS код для изменения `NSWindowStyleMask`
- Удаление `NSWindowStyleMaskClosable` (красная кнопка)
- Удаление `NSWindowStyleMaskResizable` (зеленая кнопка)
- Оставление `NSWindowStyleMaskMiniaturizable` (желтая кнопка)
- Делегат окна для постоянного контроля стиля

**Почему не работает полностью**:
- xtd framework может переопределять стиль окна после установки
- Окно может создаваться в другом потоке или с задержкой
- xtd может использовать собственный механизм управления кнопками, отличный от стандартного NSWindow

**Текущее решение**: Код для скрытия кнопок присутствует и вызывается, но визуально кнопки могут оставаться видимыми из-за особенностей xtd.

## Технические детали

### Используемые технологии
- **C++20** - основной язык разработки
- **ImGui** - immediate mode GUI библиотека (header-only)
- **SDL2** - библиотека для создания окон и обработки ввода
- **OpenGL 3.3+** - для рендеринга GUI и будущего 3D
- **CMake 3.20+** - система сборки
- **Objective-C++** - для нативной macOS интеграции (только для управления окнами)

### Сборка проекта

**Новая версия (ImGui + SDL2):**
```bash
# Установить зависимости
brew install sdl2  # macOS
# Или apt-get install libsdl2-dev  # Linux

# Скачать ImGui
cd /Users/user/Documents/driver-solution-cad
mkdir -p third_party
cd third_party
git clone https://github.com/ocornut/imgui.git

# Сборка
cd ../../build
cmake ..
make simple_gui_imgui
open simple_gui_imgui.app  # macOS
```

**Старая версия (xtd) - для справки:**
```bash
cd build
cmake ..
make simple_gui
open simple_gui.app  # macOS
```

### Важные замечания
- Меню должно быть статическим для сохранения при скрытии окна
- Закрытие приложения через `close_app::close()` использует `std::exit(0)`
- Разные окна будут иметь разные стили и поведение
- Нативная macOS интеграция используется только для специфичных задач управления окнами
