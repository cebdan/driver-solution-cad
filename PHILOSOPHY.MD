# Философия проекта - Микрокерн архитектура

## Основной принцип: Каждое решение в отдельном окне

Проект следует философии микрокерна, где каждая задача решается независимым решением (solution), работающим в своем собственном окне.

### Архитектурные принципы:

1. **Независимость решений**
   - Каждое решение (2D, 3D, Draft, BOM) работает в отдельном окне
   - Каждое окно имеет свой собственный SDL_Window, OpenGL контекст и ImGui контекст
   - Решения не зависят друг от друга и могут работать параллельно

2. **Менеджер решений (Solution Manager)**
   - Центральное окно для управления всеми решениями
   - Позволяет открывать и закрывать отдельные решения
   - Служит точкой входа в систему

3. **Изоляция задач**
   - Каждая задача имеет свой собственный интерфейс
   - Каждая задача может быть закрыта независимо
   - Состояние каждой задачи хранится отдельно

4. **Масштабируемость**
   - Легко добавлять новые типы решений
   - Каждое новое решение получает свое окно автоматически
   - Нет ограничений на количество одновременно открытых решений

### Преимущества такой архитектуры:

- **Модульность**: Каждое решение может разрабатываться и тестироваться независимо
- **Надежность**: Падение одного решения не влияет на другие
- **Гибкость**: Пользователь может работать с несколькими решениями одновременно
- **Расширяемость**: Новые решения добавляются без изменения существующего кода

### Реализация:

- Используется ImGui + SDL2 для создания окон
- Каждое окно имеет свой ImGuiContext для полной изоляции
- События обрабатываются независимо для каждого окна
- Управление жизненным циклом окон централизовано в главном цикле
